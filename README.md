# TokenHollow

TokenHollow leverages dynamic, distributed microservices for real-time processing and auto-scaling within a modular framework.

TokenHollow is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenHollow.git`
2. `cd TokenHollow`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenHollow, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
